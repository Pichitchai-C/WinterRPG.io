# WinterRPG ❄
เกม RPG พิกเซลอาร์ตธีมปีศาจ เลือด ฤดูหนาว เล่นบนเบราว์เซอร์ (HTML5 canvas)

## โครงสร้าง
- `docs/` ตัวเกม (index.html, style.css, game.js)
- `server.js` เซิร์ฟเวอร์ Node.js (ไม่ต้องติดตั้งแพ็กเกจ) ทำระบบสมัคร/ล็อกอิน และเซฟลงโฟลเดอร์ `saves/`
- `saves/` ไฟล์เซฟของผู้เล่น (รหัสผ่านเก็บแบบ scrypt hash)

## เล่นแบบมีบัญชีและเซฟในโฟลเดอร์
    node server.js
แล้วเปิด http://localhost:3000 (Node 16 ขึ้นไป)

## ขึ้น GitHub Pages
Settings > Pages > Deploy from a branch > เลือกโฟลเดอร์ `/docs`
GitHub Pages เป็น static ไม่มีเซิร์ฟเวอร์ เกมจะสลับเป็นโหมดเก็บบัญชี/เซฟในเบราว์เซอร์ (localStorage) อัตโนมัติ
โหมดนี้รหัสผ่านถูก hash แต่อยู่ในเครื่องผู้เล่นเอง ไม่เหมาะกับการป้องกันจริงจัง ใช้ ตั้งค่า > ส่งออก/นำเข้าเซฟ เพื่อสำรอง

## ปุ่มเริ่มต้น
WASD เดิน, Space โจมตี, 1/2/3 สกิล, H ฮีล, Q/E ไอเทมด่วน, F คุย, M เมนู, B กระเป๋า (เปลี่ยนได้ในตั้งค่า)
มือถือ: แตะปุ่มสกิลเพื่อเล็งอัตโนมัติ หรือลากปุ่มเพื่อเลือกทิศ

## Guest และตั้งค่า
กด "เล่นแบบ Guest" เพื่อเล่นโดยไม่สมัคร เซฟอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น (ไม่ขึ้นเซิร์ฟเวอร์)
ตั้งค่า (☰ > ⚙) ปรับขนาดปุ่มสกิล/จอยสติ๊กสำหรับมือถือได้
